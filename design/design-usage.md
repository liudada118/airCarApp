## 怎么用这份报告

1. 挑出出现次数高的色值和字号——那些就是事实上的设计规范；
2. 在 MasterGo 里把它们**建成颜色样式 / 文字样式**（起有意义的名字，如 `颜色/主色`）；
3. 再跑一次 `npm run sync:design`，这些就会带着名字进入 `src/theme/generated/`，从此可同步；
4. 最后 `npm run audit:hardcoded -- --fix` 把代码里对应的硬编码换成 token。

第 2 步是关键，也只能在 MasterGo 里做——没有名字的色值无法同步。
