# 平台标准化方案（含 AI）· 大白话版

> 一句话目标：别再「一个产品复印一份代码」了。把公共功能做成**积木**，每个产品只写一张**配置表**，
> 顺便把 **AI** 用起来——既帮我们写代码，也做进产品。

---

## 一、现在的问题

做新产品的方式 = 把整个项目**复印一份再改**（远端 `CARMain` 座椅、`sleep-monitor` 睡眠垫、一堆人名分支都是复印件）。

后果：同一个功能改一次要改好几份，各份越改越不一样，做到第 3、5 个产品就乱成一团、没法合并。

---

## 二、标准化 = 乐高积木 + 一张说明书

只做三件事：

**1. 公共积木只做一套**（所有产品共用，改一次全受益）
   - 串口连接 / 协议解析 / 点位映射 / 热力图渲染 / 数据采集下载 / 埋点

**2. 每个产品写一张「配置表」(Profile)**，把不一样的地方填进去，积木不动：
   ```jsonc
   {
     "id": "座椅",
     "串口": { "波特率": [1000000, 3000000] },
     "帧格式": { "长度": 144, "帧尾": "AA5503 99" },
     "点位": { "行": 16, "列": 12 },
     "算法": "airbag_13Hz",
     "阈值": { "在座门槛": 800 },
     "热力图": { "默认样式": "热力云图", "色阶": 425 }
   }
   ```
   → **换产品 = 换这张表。** 座椅一张、睡眠垫一张，共用同一套积木。
   （你踩过的坑：色阶 425、点位待标定、_v2 命名、存档覆盖默认值——全收进这张表管理。）

**3. 加个「假数据 / 录播」开关**
   平时开发不用每次插硬件（CH340 插平板那套）。用假数据或录下来的真实数据就能调、能测。

做完这三件，你就从"复印分支"变成"一套积木 + 多张表"。

---

## 三、把 AI 用起来（两个层面 + 一个循环）

### 层面 1：AI 帮**我们写代码**（关键收益）

> 代码越标准，AI 帮你越猛；代码越乱，AI 越容易帮倒忙。

| 有了标准化 | AI 就能… |
|---|---|
| 积木小、职责单一、有类型标注 | 只改该改的那块，不牵连全项目 |
| 有配置表 Profile | “照座椅这张表生成睡眠垫的”，几分钟出草稿 |
| 有假数据/录播 | AI 改完**自己跑起来验证对不对**，不用你插平板看 |
| 一份代码（非 N 条分支） | AI 改一次，全产品受益 |

**所以标准化 = 给 AI 铺一张干净的工作台。** 现在让 AI 改东西偶尔不靠谱，很大原因是代码环境乱。

### 层面 2：AI 做进**产品**

- **算法用 AI 模型**：坐姿/睡姿识别，比现在手写阈值更准。
- **“小可”接大模型**：能对话、根据坐姿数据给建议、自动生成健康周报。
- **数据闭环**：标准化的采集/录播，喂给 AI 训练 → 出更好模型 → 下发设备。

### 循环：越往后越省力

```
   标准化代码 → 数据变规整 → 喂给 AI 训练/使用
        ↑                        │
        └──── AI 帮我们更快写代码 ←┘
```

---

## 四、落地顺序（不要一次性重构，小步来）

| 步骤 | 做什么 | 为什么先做 |
|---|---|---|
| **① 先做「假数据 + 录播」** | 能不插硬件就开发、能录真实数据回放 | 性价比最高：立刻省事，还给 AI 验证/训练打底 |
| **② 把公共积木一块块抽出来** | 从现有座椅代码里把串口/解析/热力图等抽成独立模块，行为不变 | 小步重构，风险低 |
| **③ 写第一张配置表** | 把座椅的参数收进 Profile | 验证“配置驱动”走得通 |
| **④ 用睡眠垫验证复用** | 只写一张新表 + 挑几块积木，看能不能少写代码 | 证明标准化真的省事 |
| **⑤ 平台化 + AI 进产品** | 云/OTA、AI 模型、大模型小可 | 有了地基再往上盖 |

---

## 五、该搭哪些积木（按优先级）

**先搭这些（跨产品复用率最高）：**
- 🔌 连接/取数据的逻辑（串口连接、帧流、取压力值）
- 🌡️ 热力图组件：**热力云图** + **人体轮廓叠加**（最实用；demo 已跑通）
- 🎯 标定向导（单点按压自动学点位序）+ 阈值配置面板（你已有雏形）
- 📼 录制/回放 + 假数据源

**后面再补：** 3D 地形/柱状/粒子等炫技图、框选分析、批量采集、数据质量看板。

> 效果预研已在 `demos/pressure-viz.html`（6 种热力图形态），就是“热力图积木”的样子。
