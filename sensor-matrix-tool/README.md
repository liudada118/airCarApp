# 压力传感器矩阵分析系统（串口通信兼容不同设备上位机）

## 项目说明

本目录包含**矩侨工业 - 压力传感器验收分析系统 v2.0** 的源文件，用于在此基础上进行串口通信兼容不同设备的上位机开发与修改。

## 原始来源

- 原始部署地址：https://sensor-mtx-amhbnlex.manus.space/
- 技术栈：React + TypeScript + Vite + TailwindCSS

## 功能概述

1. **设备管理（MULTI-DEVICE）**：支持多设备管理，可添加串口和模拟设备
2. **串口配置**：波特率（默认1000000）、矩阵规格（支持10x10、32x32等）、数据位/停止位/校验
3. **通信状态监控**：实时显示设备连接状态
4. **压力矩阵显示**：ADC数值点阵实时显示
5. **CAN总线**：预留接口，后续版本支持
6. **过滤设置**：ADC过滤阈值可调
7. **自动化验收**：砝码按压验收流程
8. **数据录制/回放**
9. **批次管理**：样品记录管理

## 分支目标

本分支（`串口通信兼容不同设备上位机`）的主要目标是：

- 在现有压力传感器矩阵分析系统的基础上，增强串口通信的兼容性
- 支持不同型号/品牌的传感器设备通过串口进行数据采集
- 优化上位机与不同设备之间的通信协议适配
- 自动识别传感点位数量，界面显示网格自动适应传感点位实际大小
